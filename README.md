# Feu d'artifice en Python

Petit projet de jeu visuel réalisé avec Python et Pygame.

## Description

Ce projet affiche un ciel nocturne avec des feux d'artifice qui montent puis explosent en une pluie de particules colorées.

On peut :
- lancer des feux d'artifice automatiquement,
- cliquer pour en créer un à l'endroit voulu,
- mettre en pause avec la touche Espace,
- quitter avec Escape.

## Prérequis

Il faut avoir Python installé sur votre ordinateur.

Ensuite, installez la bibliothèque Pygame :

```bash
pip install pygame
```

## Lancer le projet

Placez-vous dans le dossier du projet puis exécutez :

```bash
python feu_artifice.py
```

## Contrôles

- Clic gauche : lancer un feu d'artifice à l'endroit du clic
- Espace : pause / reprise
- Escape : quitter

## Fichiers

- `feu_artifice.py` : code principal du jeu

## Exemple de résultat

Le programme crée une scène animée avec :
- un fond sombre,
- des étoiles,
- des fusées qui montent,
- des explosions colorées.
